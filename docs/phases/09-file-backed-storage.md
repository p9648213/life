# Phase 09: File-Backed Storage Track

Phase 09 is split into two documents:

- [Phase 09A: File-Backed Storage Foundation](09a-file-backed-storage-foundation.md) defines the generic record codec, bounded file format, and correct snapshot persistence boundary. Complete this phase before continuing the main roadmap.
- [Phase 09B: File-Storage Performance Optimization](09b-file-storage-performance-optimization.md) is a deferred, optional track for improving one measured storage bottleneck. It does not block Phase 10.

Start with Phase 09A. Continue to [Phase 10: Static Files and CSS](10-static-files-css.md) after its checkpoint, and revisit Phase 09B after benchmarking provides evidence for a specific optimization.
